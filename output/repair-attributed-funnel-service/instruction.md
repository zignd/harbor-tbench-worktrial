Apply an optional `campaigns` list only after attribution. Return `{"rows":[...]}` with one row per observed attribution campaign and every explicitly requested campaign, including zero rows for requested campaigns with no activity. Each row has string `campaign` and `campaign_name`, integer `sessions`, `purchases`, and `revenue_cents` in cents. Sort rows by descending `revenue_cents`, then ascending `campaign`.
