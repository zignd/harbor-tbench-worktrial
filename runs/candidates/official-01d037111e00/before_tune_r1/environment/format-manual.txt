Event files are UTF-8 text records. A record is a tab-separated logical line with RFC4180-style double-quoted fields: tabs and newlines inside quotes are data, and a quote is represented by two quotes. Header: H<TAB>version. Transaction start: T<TAB>transaction-id. Operation: O<TAB>transaction-id<TAB>sequence<TAB>table<TAB>primary-key<TAB>action<TAB>value-json. Commit: C<TAB>transaction-id<TAB>commit-lsn<TAB>checksum. Abort: A<TAB>transaction-id. A transaction is valid only if it has a start, operations with unique integer sequences, one commit, no abort, and checksum equal to SHA-256 of the canonical joined operation payload (the fields after O, joined with tabs and encoded as UTF-8, in sequence order). A commit LSN is an integer. Actions are upsert and delete. The output has one JSON object per live row with fields table, key, value, ordered by table then key, using compact JSON and a final newline. Values are JSON values. Reports are compact JSON with input_records, committed_transactions, ignored_transactions, live_rows, sha256.
