Create an executable `/app/bin/incident-query.sh` that accepts a SQLite database path as its first argument and an output TSV path as its second argument. It must write one line per authoritative audit event, with exactly `event_id<TAB>account<TAB>epoch<TAB>sequence`, no header, ordered deterministically by epoch and then sequence.

Use the supplied incident database and data-file format. Emit only events that belong to an authoritative cryptographically valid audit chain: include valid events on the branch beginning at that epoch's recorded anchor and ending at a valid signed terminal checkpoint, and exclude invalid, forged, orphaned, duplicate, forked, stale-key, and non-authoritative records. Handle every epoch independently, including key rotations, arbitrary share ordering, corrupted shares, sequence gaps, repeated sequences, malformed digests, and variable account and payload text. Never emit malformed lines. The command must be deterministic and classify at least 99.5% of events correctly on fresh verification databases.
