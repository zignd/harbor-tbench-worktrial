Implement and deploy the LedgerDash reconciliation feature. The deployed executable must be `/srv/ledgerdash/current/bin/ledgerdash-reconcile.js`; it must work from any directory and accept `--input PATH`, `--db PATH`, and `--config PATH`.

Read newline-delimited JSON events containing `id`, `account`, `currency`, `kind`, and decimal-string `amount`; refund events also contain `ref`. Charges and standalone adjustments contribute their signed amount, while each refund contributes the exact opposite of its referenced charge. Every id contributes at most once, duplicate lines and duplicate ids must not inflate results, and refunds may precede charges. Reject malformed records, missing references, and references to a charge in another account or currency with a useful stderr message and nonzero status.

Use exact decimal minor-unit arithmetic, including negative, zero, trailing-zero, and positive or negative tie values. On success, transactionally rebuild the SQLite database at `--db`, leaving fresh `events`, `reconciliation_totals`, and `reconciliation_meta` tables. The totals table must contain exactly one row per account/currency with columns `account`, `currency`, `event_count`, `total_minor`, and canonical two-decimal `total`; queries ordered by account and currency must be sorted. Event counts are accepted unique events. Metadata must include the input SHA-256, accepted unique-event count, and release version.

Create a deterministic npm package under `/opt/ledgerdash/dist/` containing the runnable feature, its required configuration, and the supplied amount-normalization helper. `./bin/ledgerdash deploy` must build and install it, preserve existing CLI commands, atomically update `/srv/ledgerdash/current`, and create `/srv/ledgerdash/releases/<version>/manifest.json` containing the release version, package SHA-256, and deployed-file list. The deployed feature and helper/config must work without repository access. The visible fixture is only a sample; support large fresh inputs, multiple currencies and groups, changed-input reruns, and repeated identical runs.
