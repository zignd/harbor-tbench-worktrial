JSON lines use base64 payloads. The epoch key is SHA256 of the bytes epoch-key: followed by the decimal epoch. An event MAC is HMAC-SHA256 over tenant UTF-8 bytes, epoch as four-byte big-endian, seq as eight-byte big-endian, payload length as four-byte big-endian, and payload bytes. A root starts at 32 zero bytes and hashes the previous root plus binary MAC in numeric sequence order. A transition MAC uses the old epoch key over tenant bytes and old and new epochs as four-byte big-endian values.
