Sensor Wire Relay Protocol
A frame is MAGIC(4 bytes, SWR1), LENGTH(4 byte unsigned big endian), BODY, CRC(4 byte big endian CRC32C of BODY). BODY begins with VERSION byte 1. Strings are unsigned-varint length followed by UTF-8 bytes. Integers use unsigned varints; signed values use zig-zag. The body contains identifier string, sequence unsigned varint, timestamp signed zig-zag, measurement count followed by key string and signed value pairs, and metadata count followed by key/value strings. Additional trailing TLV records are encoded as type byte, unsigned length, and bytes and are ignored when type is not recognized.
