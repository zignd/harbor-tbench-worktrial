Requests and responses are one JSON object per newline. Lookup success has ok, device, at, value, quality, source_sequence. History success has ok, device, records; each record has at, value, quality, source_sequence. Stats has ok, generation, records, devices, rejected_frames. Reload has ok and generation. Missing data returns {"ok":false,"error":"not_found"}; malformed requests return invalid_request; unknown operations return unknown_operation. History bounds are inclusive and records are ordered by at then source_sequence. For duplicate device/timestamp records, retain higher quality, then higher uint32 source sequence. Generation is an increasing integer.
