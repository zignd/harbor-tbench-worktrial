# Incident replay
Input tables are raw_events(id,occurred_at,actor,kind,payload,source,seq,depends_on,correlation_key), actor_aliases(alias,canonical,valid_from,valid_to), policy_versions(version,effective_from,effective_to,ack_minutes,resolve_minutes), and optional source_cursors/replay_metadata. Dependencies are comma-separated ids. Alias intervals are half-open. Merge events have payload JSON `{"merge":"KEY"}`. Corrections use `corrects`, supersession uses `supersedes`, and tombstones use `tombstone` in payload. Events are ordered by dependency, then seq, timestamp, id; cycles break by the smallest remaining id.
