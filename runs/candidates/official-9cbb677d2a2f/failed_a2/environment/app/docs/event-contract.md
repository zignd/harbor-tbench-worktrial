Timestamps are ISO UTC strings and comparisons are lexical after normalization. Correlation uses correlation_key and resolved actor; a merge payload joins the named key. An alias applies when valid_from <= timestamp and timestamp < valid_to (NULL means unbounded). Dependencies are hard when present and existing, optional when absent. Canonical state uses surviving events after the supersession/correction/tombstone reduction. A policy interval is half-open and the latest effective_from wins. Audit hashes are SHA-256 over canonical JSON.
