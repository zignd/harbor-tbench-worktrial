# Incident replay contract

Input tables are raw_events(id INTEGER PRIMARY KEY, source TEXT, source_seq INTEGER, occurred_at TEXT, actor TEXT, correlation TEXT, event_type TEXT, payload TEXT, depends_on TEXT, correction_of TEXT, supersedes TEXT), actor_aliases(alias TEXT, canonical_actor TEXT, valid_from TEXT, valid_to TEXT), policy_versions(version TEXT PRIMARY KEY, effective_from TEXT, effective_to TEXT, ack_minutes INTEGER, resolve_minutes INTEGER), source_cursors(source TEXT PRIMARY KEY, cursor INTEGER), and replay_metadata(key TEXT PRIMARY KEY, value TEXT).

Output tables are archival_events(source_id INTEGER PRIMARY KEY, source TEXT, source_seq INTEGER, occurred_at TEXT, original_actor TEXT, resolved_actor TEXT, correlation TEXT, event_type TEXT, payload TEXT, depends_on TEXT, correction_of TEXT, supersedes TEXT), incidents(incident_id TEXT PRIMARY KEY, correlation TEXT, opened_at TEXT, resolved_at TEXT, final_state TEXT), incident_events(incident_id TEXT, source_id INTEGER, ordinal INTEGER, PRIMARY KEY(incident_id,source_id)), transitions(incident_id TEXT, ordinal INTEGER, source_id INTEGER, state TEXT, actor TEXT, policy_version TEXT, occurred_at TEXT, PRIMARY KEY(incident_id,ordinal)), sla_windows(incident_id TEXT, source_id INTEGER, policy_version TEXT, start_at TEXT, end_at TEXT, PRIMARY KEY(incident_id,source_id)), replay_audit(incident_id TEXT PRIMARY KEY, event_count INTEGER, digest TEXT).

Timestamps are ISO UTC strings. An alias is active when valid_from <= occurred_at and (valid_to is null or occurred_at < valid_to). Correlation is the primary grouping key; events with merge links in payload JSON (`merge_into`) join that component. Resolve aliases before grouping. Dependencies are comma-separated source ids; absent, empty, and null values mean no dependency. Order is stable Kahn topological order: ready nodes sort by occurred_at, source_seq, source, id; if a remaining cycle exists, remove the same smallest key node and continue. A correction replaces the referenced event's logical effect, supersedes does likewise, and tombstone removes its target; reductions happen after ordering. State starts open, `ack` becomes acknowledged, `resolve` becomes resolved, and `reopen` becomes open. SLA uses the policy interval covering each event timestamp.
