Implement the missing recovery feature in /opt/ledgerforge. Create an executable /opt/ledgerforge/bin/recover.py that accepts one RFX archive path and an optional --out PATH argument. It must write canonical UTF-8 JSON to PATH, or to stdout when --out is omitted. The JSON must contain records, total, and status. records must contain every recoverable logical observation exactly once, sorted by integer seq, with each item represented as {"seq": integer, "value": reduced-fraction-string}. total must be the exact reduced rational sum, using 0, integer strings, or p/q strings with a positive denominator and no floating point. status must be complete when no reconstruction was needed and recovered when damaged or truncated frame data was reconstructed.

Support RFX archives with physically reordered frames, duplicate frame copies, zero and negative values, arbitrary-size coefficients, signed decimal exponents including negative exponents, cancellation, and varints larger than one byte. Validate checksums and payload structure before accepting a frame. Use parity redundancy to reconstruct a missing or damaged observation when sufficient information exists. If an observation cannot be recovered, exit nonzero and emit a concise error without inventing a value. Results must be independent of frame ordering, duplicates, and whether recovery was needed. Use only the Python standard library and do not modify /opt/ledgerforge/bin/report.py or supplied data; the existing report command must retain its behavior.
