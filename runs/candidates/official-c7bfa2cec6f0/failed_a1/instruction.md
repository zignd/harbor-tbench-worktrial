Repair the recovery service under /opt/reconstructd and install it as /usr/local/bin/reconstructd. It must run without network access, use at most one CPU and 2 GB of memory, listen on TCP port 7077, accept JSON Lines, and return exactly one JSON object for every request line.

A run begins with begin {op,run_id,channels,calibration,modes}, accepts frame and correction operations, then finalize, then query. frame contains seq and base64 packed bytes. correction contains seq and one additive correction per channel. Reject malformed requests and operations in the wrong phase with an error object and do not mutate the run. Support multiple independent run IDs on one connection. query is valid only after finalize and must return the cached report unchanged.

Validate every frame's base64, length, signed little-endian int16 channel values, and CRC-16/CCITT. Reject invalid frames. Valid duplicate sequence numbers replace the earlier frame and increment duplicate. Sort accepted sequences numerically. Count accepted, rejected, duplicate, and missing frames; missing is the number of integer sequence gaps between the smallest and largest accepted sequence and must not create observations.

Apply the selected calibration revision and the sequence's raw-channel corrections before decoding every valid frame with /usr/local/libexec/modalcodec. The packed decoder request and calibration revisions are documented in /opt/reconstructd/README.protocol. Compute modal mean and population covariance using only decoded observations. Return the requested mode count capped at the available decoder modes. Return covariance eigenvalues in descending order and normalized eigenvector columns with the largest-magnitude component of each eigenvector positive; clamp only tiny negative roundoff eigenvalues. Numeric values must be within 1e-8 relative error and 1e-10 absolute error near zero.

The finalized report must contain run_id, calibration, counts with accepted/rejected/duplicate/missing, mean, covariance, eigenvalues, and eigenvectors. Preserve deterministic behavior across restarts and write no network-dependent code. Verify /usr/local/bin/reconstructd by starting it and exercising the documented TCP protocol before finishing.
