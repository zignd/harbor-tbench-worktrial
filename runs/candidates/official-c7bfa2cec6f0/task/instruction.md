Repair the recovery service under /opt/reconstructd and install it as /usr/local/bin/reconstructd. It must run without network access, use at most one CPU and 2 GB of memory, listen on TCP port 7077, accept JSON Lines, and return exactly one JSON object for every request line.

Implement the protocol in /opt/reconstructd/README.protocol. A run begins with begin and then accepts frame and correction requests, followed by finalize and query. Support multiple independent run IDs on one connection. Validate all request shapes, types, values, base64, payload lengths, signed little-endian int16 channels, and CRC-16/CCITT; return the documented errors for malformed requests, unknown runs, and invalid phases without changing state. Valid duplicate frames must replace earlier valid frames and increment duplicate. Sort accepted sequences, count integer gaps as missing observations, and exclude gaps from all statistics.

Support calibration revisions 1, 2, and 3 exactly as documented. Apply each sequence's additive finite numeric correction to raw channel values before invoking /usr/local/libexec/modalcodec for every accepted frame. Retain the requested mode count capped at the available channel modes. Compute the modal mean and population covariance over accepted decoded observations only. Return exact report fields and counts documented in the README, descending eigenvalues, normalized deterministically signed eigenvectors, and only clamp tiny negative roundoff eigenvalues. Numeric results must be within 1e-8 relative error and 1e-10 absolute error near zero.

Finalize must cache its report atomically, and query must return the unchanged cached report. Preserve state across valid independent runs, reject operations after finalization except query, and remain deterministic across restarts. Verify /usr/local/bin/reconstructd by starting it and exercising the TCP protocol before finishing.
