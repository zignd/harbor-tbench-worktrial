Funnel service protocol: GET /health returns {"status":"ok"}. POST /v1/reset accepts {} and returns {"ok":true}. POST /v1/append accepts {"events":[event objects]} and returns {"accepted":integer}. POST /v1/report accepts {"since":ISO-8601,"until":ISO-8601,"campaigns":[strings]} and returns {"rows":[{"campaign":string,"sessions":integer,"purchases":integer,"revenue_cents":integer}]}. Campaigns is optional. Ranges are UTC half-open intervals.
