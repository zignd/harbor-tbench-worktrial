Burst replay protocol: see /opt/burstreplay/FORMAT.md. JSONL requests are reset, ingest, and report. Each request has string run. Ingest has trace. Reports contain events, sessions, units, peak, histogram, and checksum. Records are ordered by timestamp and stable arrival index, sessions split at gaps greater than 60000 ms, and units are value times weight. CRC32 uses UTF-8 bytes and lowercase eight-digit hexadecimal output.
