# Assay cohort reproducer

The command is `python -m assay_report DATABASE OUTPUT`. The database is SQLite and has tables `export_fragments(fragment_id INTEGER PRIMARY KEY, payload BLOB)`, `runs(run_id TEXT PRIMARY KEY, slope REAL, intercept REAL, calibration_unit TEXT)`, `measurements(measurement_id TEXT PRIMARY KEY, cohort TEXT, analyte TEXT, run_id TEXT, well TEXT, sequence INTEGER, quality REAL, timestamp INTEGER, value REAL, unit TEXT, crc32 TEXT, fragment_id INTEGER)`, `controls(measurement_id TEXT, cohort TEXT, analyte TEXT, role TEXT)`, `cohorts(cohort TEXT PRIMARY KEY, analyte TEXT, include INTEGER DEFAULT 1)`, and `unit_factors(unit TEXT PRIMARY KEY, factor REAL)`. A catalog may put records only in fragments, or may use measurements as a source table; implementations must not write it.

A fragment payload is UTF-8 JSON-lines. Each record has `id, cohort, analyte, run, well, seq, quality, timestamp, value, unit, role`; `run` identifies `runs.run_id`. The optional `crc32` is eight lowercase hexadecimal digits and is CRC32 of the canonical compact JSON encoding of the record with its `crc32` member omitted. A line that is not JSON does not invalidate neighboring lines. Fragment payloads are concatenated in ascending fragment_id before scanning, so a JSON record may cross a fragment boundary; a truncated final line is ignored. Required fields must have the stated scalar types, finite numeric values, and a known run and unit. IDs are unique after recovery.

For a duplicate `(cohort, analyte, run, well, seq)`, retain the greatest tuple `(quality, timestamp, id)`; ties are resolved lexicographically by id. A record from `measurements` is also eligible, with its fields mapped to the fragment names, and is deduplicated together with recovered fragment records by the same rule. Convert a value to the run calibration unit by multiplying by `unit_factors[source] / unit_factors[calibration_unit]`, then calculate `calibrated = slope * converted + intercept`.

Only rows with `cohorts.include=1` are eligible. For each cohort/analyte, split eligible calibrated rows into `role=sample`, `role=positive`, and `role=negative`. Within each role, remove Tukey outliers using the README convention: quartiles are linear interpolation at `(n-1)/4` and `3(n-1)/4`, and retain values satisfying `q1-1.5*(q3-q1) <= x <= q3+1.5*(q3-q1)`. Controls are computed after this same filtering. The sample statistic is its median. The control statistic is the median of positive controls, otherwise the median of negative controls when present; if no control exists it is null. The effect is the Hodges–Lehmann estimate, the median of every sample-control pairwise difference, and is null if either side is empty. `n` and `control_n` count surviving rows. A cohort row is emitted when it is listed in `cohorts` and has at least one eligible sample or control; empty cohorts are emitted with null statistics and zero counts.

Output is an array of objects with exactly `cohort`, `analyte`, `n`, `control_n`, `median`, `control_median`, `effect`, and `unit`. Unit is the run calibration unit when a statistic exists, otherwise null. Numbers are ordinary JSON finite numbers; non-computable values are JSON null. Rows are sorted by `(cohort, analyte)` and serialized compactly with a final newline.
