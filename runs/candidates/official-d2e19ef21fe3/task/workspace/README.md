# Assay cohort reproducer

Run `python -m assay_report DATABASE OUTPUT`. SQLite catalogs contain `export_fragments(fragment_id INTEGER PRIMARY KEY, payload BLOB)`, `runs(run_id TEXT PRIMARY KEY, slope REAL, intercept REAL, calibration_unit TEXT)`, `measurements(measurement_id TEXT PRIMARY KEY, cohort TEXT, analyte TEXT, run_id TEXT, well TEXT, sequence INTEGER, quality REAL, timestamp INTEGER, value REAL, unit TEXT, crc32 TEXT, fragment_id INTEGER)`, `controls(measurement_id TEXT, cohort TEXT, analyte TEXT, role TEXT)`, `cohorts(cohort TEXT PRIMARY KEY, analyte TEXT, include INTEGER DEFAULT 1)`, and `unit_factors(unit TEXT PRIMARY KEY, factor REAL)`.

A fragment payload is UTF-8 JSON-lines. Each record has `id, cohort, analyte, run, well, seq, quality, timestamp, value, unit, role`; optional `crc32` is eight lowercase hexadecimal digits and is CRC32 of canonical compact sorted-key JSON with that member omitted. Scan the concatenated fragment byte stream in fragment_id order. Malformed lines do not invalidate neighboring lines; a record may cross fragment boundaries; an incomplete final line is ignored. Required fields have scalar types, finite numeric values, known run and unit, and role is sample, positive, or negative. Measurement rows map to the same fields and are combined with fragment records.

For duplicate `(cohort, analyte, run, well, seq)`, retain the greatest `(quality, timestamp, id)`. Convert from source units using `value * source_factor / calibration_factor`, then use `slope * converted + intercept`. Only cohorts with `include=1` participate. For each cohort/analyte, remove Tukey outliers separately in each role. Quartiles linearly interpolate at `(n-1)/4` and `3(n-1)/4`; retain values on the inclusive fences `q1-1.5*(q3-q1)` through `q3+1.5*(q3-q1)`. Use the median of surviving samples, and positive controls, or negative controls if no positive survives. The effect is the median of every sample-control difference. A listed cohort is emitted if it has any eligible row, including an empty listed cohort; counts are surviving rows, and unavailable statistics are null. Unit is the calibration unit when a statistic exists, otherwise null. Output fields are exactly `cohort, analyte, n, control_n, median, control_median, effect, unit`, sorted by `(cohort, analyte)`, compact UTF-8 JSON plus newline, with no NaN or Infinity.
