replayd is a newline-delimited JSON service. Requests are objects with op recover, get, list, put, delete, stats, manifest, or audit. get/list/stats/audit require tenant where applicable; get also requires key, list accepts prefix, put requires value, and delete requires key. Successful responses have ok:true. get returns value:null when absent. list returns items [{key,value}] sorted by key. stats returns live and events. manifest returns generation and checksum. audit returns events [{key,value,op,tx}] in replay order. Errors are {ok:false,error:string}.
