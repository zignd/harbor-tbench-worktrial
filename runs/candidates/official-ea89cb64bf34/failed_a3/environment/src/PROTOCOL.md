The daemon reads and writes one JSON object per line. Operations are recover, get, list, put, delete, stats, manifest, and audit. Requests use op plus tenant/key/prefix/value as applicable. Successful get is {ok,found,value}; list is {ok,objects:[{key,value}]}; stats is {ok,tenant,live,events}; manifest is {ok,generation,checksum}; audit is {ok,events}. Mutations and recovery return {ok:true}; failures return {ok:false,error}.
