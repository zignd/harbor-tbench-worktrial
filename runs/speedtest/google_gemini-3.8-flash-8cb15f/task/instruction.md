Hey, we need to wrap up the telemetry migration service in /opt/telemetry-service. The old ingress stripped downstream trace headers, so frontend edge logs and backend worker logs in /var/log/telemetry/ have no matching request IDs. We need the query daemon (telemetry-queryd) running on port 8085 to serve /v1/query and /v1/attribution/stats. The API specification and log schema notes are in README.md and docs/spec.md. The log unpacker needs to decode the legacy compact .bpack binary logs (there's a legacy C header and a partial prototype in legacy/), the engine needs to solve the temporal bipartite matching constraints between frontend requests and backend tasks, and then compute the windowed latency percentiles. Once you have it running and passing the queries, make sure systemctl restart telemetry-queryd (or equivalent service script) stays healthy.
